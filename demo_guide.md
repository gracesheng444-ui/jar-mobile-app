# Trying the Shared Memory Jar Demo

Want to see how the app works before making an account? The demo drops you straight into a real, fully working jar — pre-loaded with a week of history — so you can try everything without signing up or asking anyone else to join.

## Starting the demo

Go to [sharedmemoryjar.com](https://sharedmemoryjar.com) and tap **"Try a live demo — no account needed"** on the sign-in screen. That's it — no email, no password. You'll land straight in a jar with 6 days of star-dropping history already in it, as if you and a partner had been using it for about a week, plus "today" waiting for you to try.

## What you'll find already in it

- A run of days where both sides tapped, some with notes attached.
- One day that was missed entirely and never repaired.
- One day that *was* missed but got repaired.
- "Today," which is deliberately sitting in a missed, unresolved state — so the very first thing you can try is the app's signature mechanic.

## Things to try

- **Use repair** — restores today's streak back to where it was before the miss.
- **Tap instead of repairing** — forfeits the repair and starts a fresh streak at 0. Try this in a second demo (see below) if you want to see both outcomes.
- **Open the Calendar tab** and tap into any past day to see the notes left on it.
- **Attach a note** after tapping, to see how that's shown to your (demo) partner.
- **Change the meet-up date** and watch the star count adjust.

## Resetting or exiting

- **Reset demo** puts your jar right back to its original starting state — same 6-day history, same "missed and waiting" today — so you can try a different path (repair vs. tap) without needing a new one.
- **Exit demo** signs you out. Nothing about the demo is tied to a real account, so there's nothing to clean up on your end.

Your demo session stays signed in on this device until you tap "Exit demo," so you can close the tab and come back to the same jar later. Each time you start a fresh demo from the sign-in screen (rather than returning to one already open), it creates its own private jar — nobody else can see or affect it.
